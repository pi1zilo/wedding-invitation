# Отчёт рефакторинга

## Что было найдено

### Проблемы структуры
- CSS минифицирован: 153 строки в компактном формате, невозможно редактировать
- Шрифты подключены через `local()` — не загружаются из файлов проекта
- Имена файлов assets — хеши, непонятно что где

### Дублирование
- Позиции цветов повторяются между экранами 1, 2 и 4 (один и тот же макет)
- CSS-переменные отсутствовали — значения дублировались в разных местах

### Потенциальные ошибки
- `@font-face` использовал `local()` вместо `url()` — шрифты не загружались из файлов
- 6 файлов в `assets/` не используются (хранятся без дела)

### Неиспользуемый код
- 6 изображений в `assets/` не подключены ни в HTML, ни в CSS:
  - `assets/e0f18a8b2ba3887ea0d4ee94cdce527c6bd6f7db`
  - `assets/cd432ecff8f89161a70a75ed7434396a6f5df2af`
  - `assets/c3b6db34e04092594914f9ac2af8c8c85554610f`
  - `assets/8e85c2830ee92c72999b4b0cce81a5616a4e39af`
  - `assets/144199ce96c8b1ba1f2489e30dfbe5d13323ea7c`
  - `assets/121738b93bb1b86ac5812cfe4e5c0439b443b340`

## Что было изменено

### `style.css` — полная переработка

| Что | Зачем |
|-----|-------|
| Форматирование: развернутый стиль вместо минификации | Читаемость и удобство редактирования |
| CSS-переменные (`:root`) для цветов, шрифтов, размеров | Централизованное управление дизайном |
| Разделение на 10 логических блоков с комментариями | Быстрый поиск нужного стиля |
| Исправление `@font-face`: `url()` вместо `local()` | Шрифты теперь загружаются из файлов проекта |
| Добавлен fallback для Newston (шрифт отсутствует в проекте) | Корректное отображение амперсанда |

### `script.js` — улучшение читаемости

| Что | Зачем |
|-----|-------|
| IIFE-обёртка | Изоляция переменных, защита от глобальной области |
| Константы `SCREEN_WIDTH`, `SCREEN_HEIGHT` | Понятные имена вместо магических чисел |
| Проверка существования элементов | Защита от ошибок, если HTML изменится |
| Комментарии к логике | Объяснение purpose кода |

### `index.html` — структурирование

| Что | Зачем |
|-----|-------|
| Секционные комментарии с описанием экранов | Быстрое понимание структуры |
| Форматирование длинных строк | Читаемость текстов |
| HTML-сущность `&#10038;` вместо `✦` | Явное указание символа |
