# Свадебное приглашение — Айзирек & Таштемир

Интерактивное свадебное приглашение (27.09.2026). Мобильный дизайн 393×3981 px, масштабируется под любой экран.

## Структура проекта

```
├── index.html          ← главная (и единственная) страница
├── style.css           ← все стили
├── script.js           ← логика перехода от заставки к приглашению
├── fonts/              ← шрифты проекта
│   ├── roseversailles1.ttf
│   ├── DolomanPavljenko.otf
│   ├── Sensal Regular (RUS by Slavchansky)_0.ttf
│   └── Cruinn Thin.ttf
└── assets/             ← изображения (фоны, цветы, фото)
    ├── e3d6e603...      ← фоновое фото (используется на экранах 1, 2, 4)
    ├── 8765933c...      ← цветок (верхний, используется везде)
    ├── dae64a36...      ← цветок (нижний, используется везде)
    ├── 712009ee...      ← мраморный текстура (экран 3)
    ├── 548f5207...      ← лоза/виноград
    ├── 4199d186...      ← обручальные кольца
    └── b7468d1e...      ← фото ресторана
```

## Как запустить

Откройте `index.html` в браузере. Никакого сервера не нужно.

## Где что менять

### Тексты

| Что | Где |
|-----|-----|
| Имена жениха/невесты | `index.html` — строки 41–43 |
| Дата свадьбы | `index.html` — строка 45 |
| Приветствие гостям | `index.html` — строка 57 |
| Информация о ресторане | `index.html` — строка 68 |
| Надпись "Ждем Всех Вас" | `index.html` — строка 73 |

### Шрифты

Все шрифты подключены в `style.css` (раздел 1. FONTS).

| Шрифт | Файл | Где используется |
|-------|------|------------------|
| RoseVersailles1 | `fonts/roseversailles1.ttf` | Заголовки, кнопка, имена |
| Doloman | `fonts/DolomanPavljenko.otf` | Обычный текст, примечания |
| Sensal | `fonts/Sensal Regular...ttf` | Надпись "приглашаем на свадьбу" |
| Cruinn | `fonts/Cruinn Thin.ttf` | Дата |

### Цвета

Все цвета в CSS-переменных (`style.css`, раздел 2. CSS VARIABLES):

| Переменная | Значение | Назначение |
|------------|----------|------------|
| `--ink` | `#151515` | Основной цвет текста |
| `--bg-page` | `#111` | Фон страницы |
| `--bg-stage` | `#f7f7f5` | Фон stage |
| `--bg-white` | `#fff` | Белый фон |

### Изображения

Все изображения в папке `assets/`. Замените файл, сохранив имя (хеш).

### Размеры и расположение

Все размеры и позиции — в `style.css`, разделы 6–9. Каждый экран — отдельный блок.

### Анимации

| Что | Где |
|-----|-----|
| Исчезновение заставки | `style.css` — `.click-screen.hide` |
| Плавная прокрутка | `script.js` — `behavior: 'smooth'` |

## Адаптивность

Адаптивность реализована через CSS-переменную `--scale` и `transform: scale()` в `.design`. Медиа-запрос в конце `style.css` добавляет тень и отступ для экранов шире 393px.

## Файлы, которые лучше не менять

- `assets/` — изображения (только заменять файлы, не переименовывать)
- `fonts/` — шрифты (только заменять файлы)
- Координаты и размеры в CSS — точная копия Figma-макета
