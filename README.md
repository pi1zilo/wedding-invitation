# Wedding invitation — Figma 1:1 mobile layout

Первая страница сделана отдельным экраном: на ней только «Нажми».
После нажатия выполняется переход к следующему экрану приглашения.

Размер исходного мобильного дизайна: 393 px по ширине.
Все изображения взяты из исходного Untitled.fig.

## Запуск
Просто открой `index.html` в браузере.

Для максимально близкого совпадения с Figma установи используемые дизайнером шрифты:
- Rose Versailles1
- Newston Normal
- Sensal
- Cruinn Thin
- Doloman Pavljenko Light

Если шрифты есть на системе, браузер использует их через `local()`.
